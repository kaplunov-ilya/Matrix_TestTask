# Matrix — тестовое задание

Задача: по двум наборам матриц трансформаций (`model` и `space`, JSON) найти все смещения, при которых модель целиком совпадает с пространством, и визуализировать результат.

## Как устроено
- **MatrixParser** загружает матрицы из JSON (Newtonsoft.Json).
- **MatrixOffsetFinder** перебирает кандидаты `offset = space × model⁻¹` и проверяет каждый. Для проверки матрицы пространства заранее складываются в `HashSet`, поэтому поиск совпадения работает за O(1), а не перебором.
- Поиск асинхронный (UniTask) и отдаёт управление кадру каждые 50 итераций, поэтому приложение не зависает на больших данных.
- **CubeCreator / CubeVisualizePresenter** строят кубы и подсвечивают найденные совпадения. Логика поиска не зависит от визуализации.
- **EntryPoint** собирает зависимости вручную, без глобальных синглтонов.

## Стек
Unity 6, C#, UniTask, Newtonsoft.Json, URP
